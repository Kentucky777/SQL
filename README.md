# Airline Data Analytics & Relational Database Platform

Проект по моделированию предметной области, построению реляционной базы данных и решению комплекса аналитических бизнес-задач авиакомпании в среде **PostgreSQL**.

---

## 📌 Цели и задачи проекта
* **Системный и бизнес-анализ:** декомпозиция предметной области (пассажирские авиаперевозки), проектирование сущностей, атрибутов и ограничений целостности (PK, FK, UNIQUE).
* **Разработка витрин и аналитических выборок:** расчет ключевых операционных и коммерческих метрик (динамика выручки, загрузка рейсов, воронка оформления билетов).
* **Обработка и безопасность данных:** реализация маскирования ПДн (152-ФЗ), работа со сложными строковыми структурами и временными рядами.

---

## 🛠 Стек технологий
* **СУБД:** PostgreSQL 15+
* **Инструменты:** pgAdmin, Git
* **Язык запросов:** SQL (DDL, DML, CTE, Window Functions, Aggregate Functions)

---

## 🗂 Архитектура и структура базы данных

База данных включает 12 связанных таблиц, охватывающих основные бизнес-процессы: расписание полетов, фактические вылеты, управление парком ВС, финансовые заказы, персональные билеты, брошенные корзины и журнал операционных событий.

---

📊 Решенные аналитические кейсы
1. Операционная аналитика и логистика
Хронометраж наземного обслуживания: с помощью оконной функции LAG() рассчитана длительность межоперационных переходов между статусами вылета в базовом хабе (Пулково) для оптимизации наземных служб.

Анализ узких мест в расписании: группировка сбоев и отклонений по дням недели (EXTRACT(DOW)).

Мониторинг парка воздушных судов: выявление бортов, закрепленных только за одним направлением, для перераспределения маршрутной сети.

2. Коммерческая и финансовая аналитика
Кумулятивная выручка (нарастающий итог): расчет динамики поступления денежных средств по каждому маршруту за квартал через аналитические оконные функции.

Ранжирование продаж: вычисление плотного ранга цен билетов внутри конкретных рейсов (DENSE_RANK) для проверки алгоритмов динамического ценообразования.

Анализ воронки продаж и потерь: выявление «брошенных корзин» (зарезервированные бронирования без оформленных билетов через LEFT JOIN ... IS NULL).

Оценка маржинальности направлений: цепочка CTE для сопоставления фактической выручки с условными затратами на минуты полета.

3. Управление клиентским опытом и безопасность
Маскирование персональных данных (ПДн): автоматическое сокрытие серий/номеров паспортов (SUBSTRING, REPLACE) и нормализация ФИО пассажиров до формата «Фамилия И.О.».

Сегментация пассажиропотока: классификация глубины бронирования (в день вылета / краткосрочно / долгосрочно) через условия CASE.

Перекрестный анализ семейных перевозок: нахождение пересечения списков (INTERSECT) взрослых клиентов, оплачивающих билеты для детей.
