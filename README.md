# 🚀 Relational Database & Data Analytics Portfolio (PostgreSQL)

## 🧭 Навигация по модулям проекта

Репозиторий структурирован по двум ключевым отраслевым направлениям:

### ✈️ [Модуль 1: Airline Data Platform (Авиаперевозки)](./01_airline_platform)
* **Предметная область:** Комплексная система пассажирских авиаперевозок (12 связанных таблиц).
* **Ключевой фокус:** Логистика, хронометраж наземного обслуживания, маскирование персональных данных (152-ФЗ), перекрестный анализ семейных перевозок.
* **Технологии:** `EXTRACT(DOW)`, `CASE`, `SUBSTRING`, `INTERSECT`, цепочки подзапросов, DDL/DML.

### 💳 [Модуль 2: Fintech & E-commerce Platform (Финтех и Ретейл)](./02_fintech_and_ecommerce)
* **Предметная область:** Банковский процессинг (клиенты, счета, транзакции) и электронная коммерция (заказы, позиции чека, товарные категории).
* **Ключевой фокус:** Когортный анализ оттока (Anti-Join), аудит аномальных расходов (`LAG`), накопительный баланс (`Running Total`), определение бестселлеров в категориях (`Top-1 via CTE + ROW_NUMBER`).
* **Технологии:** Оконные функции ранжирования и смещения, обобщенные табличные выражения (CTE), условная агрегация, безопасная математика (`NULLIF`, `COALESCE`).

## 🛠 Технологический стек и аналитический инструментарий
* **СУБД:** PostgreSQL 15+
* **Инструменты администрирования:** pgAdmin, DBeaver, Git
* **Диалекты и стандарты:** ANSI SQL, PL/pgSQL
* **Ключевые навыки:**
  * **Реляционное проектирование:** Нормализация (1НФ, 2НФ, 3НФ), ссылочная целостность (`PK`, `FK`, `CASCADE`/`RESTRICT`), ограничения бизнес-правил (`CHECK`, `UNIQUE`, `NOT NULL`).
  * **Аналитические оконные функции:** `ROW_NUMBER()`, `DENSE_RANK()`, `RANK()`, `LAG()`, `LEAD()`, секционирование (`PARTITION BY`), кумулятивные суммы (`SUM() OVER (...)`).
  * **Оптимизация и сложные конструкции:** Обобщенные табличные выражения (`WITH` / CTE), многотабличные джойны (`INNER`, `LEFT`, `FULL OUTER`), Anti-Join паттерны.
  * **Обработка данных и безопасность:** Семантика трехзначной логики (3VL), обработка неопределенных значений (`IS NULL`, `COALESCE`), маскирование чувствительных данных.
